---
tag: m6400
title: Read file from SD card
brief: Print the contents of a file as Base64
author: kaedenn

group: sd

codes: [ M6400 ]
related: [ M6401 ]

notes: This command requires a custom build of Marlin.

parameters:

- tag: A
  optional: true
  description: Dump file as plain text, not Base64.
  values:
  - type: flag

- tag: R
  optional: true
  description: Don't write the Base64 prefix on every line.
  values:
  - type: flag

- tag: S
  optional: true
  description: If memory export is enabled, dump memory region starting at this address.
  values:
  - tag: start
    type: int

- tag: E
  optional: true
  description: If memory export is enabled, dump memory region ending at this address (conflicts with L).
  values:
  - tag: end
    type: int

- tag: L
  optional: true
  description: If memory export is enabled, dump memory region of this length (conflicts with E).
  values:
  - tag: length
    type: int

examples:
- pre: Dump a file as Base64
  code:
  - M6400 mc.zip

- pre: Dump a file as text
  code:
  - M6400 A file.gcode

---

Note that M6400 S requires the `BINARY_BASE64_MEMORY_DUMP` feature enabled.
